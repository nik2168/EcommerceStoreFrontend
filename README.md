# Nox-Cart

Nox-Cart is a full-featured e-commerce platform built as a Master's project, designed to deliver a modern, engaging, and intelligent shopping experience. Every aspect of the platform is crafted to maximize user engagement, from smooth product animations to seamless payment flows and advanced AI-driven personalization.

Live Link - http://noxcart.vercel.app

## 🚀 Key Features

- **AI Assistant**  
  Integrated AI chatbot for personal help, product suggestions, and natural language queries. The assistant leverages NLP to understand and assist users in real time.

- **Personalized Recommendations**  
  Utilizes machine learning (TensorFlow.js) and cosine similarity algorithms to analyze user interactions and product ratings, delivering highly accurate, personalized product recommendations.

- **Stripe Payment Gateway**  
  Secure and smooth payment processing with Stripe, including animated payment success screens and best-in-class UI for payment redirection.

- **Admin Panel**  
  Comprehensive admin dashboard for inventory management and live insights into product performance and sales.

- **Real-Time Communication**  
  WebSockets integration ensures low-latency interactions between the AI assistant and users, providing instant responses and updates.

- **Cloudinary Image Optimization**  
  All product images are optimized and delivered via Cloudinary, improving website performance and load times.

- **Automated Email Notifications**  
  Upon successful payment, order details are automatically sent to users via email using Nodemailer, ensuring a professional and informative post-purchase experience.

## 🛠️ Tech Stack

- **Frontend:** ReactJS, TailwindCSS, DaisyUI
- **Backend:** Node.js, Express.js, MongoDB
- **AI & ML:** TensorFlow.js, Custom Recommendation Engine
- **Payments:** Stripe
- **Media:** Cloudinary
- **Real-Time:** Socket.IO
- **Email:** Nodemailer
